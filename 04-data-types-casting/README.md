## Особенности типизации в PHP

PHP — **динамически типизированный** язык: тип переменной определяется автоматически при присвоении значения и может меняться в процессе выполнения. Проверка типов происходит **во время выполнения** (runtime), а не при компиляции.

Это даёт гибкость, но создаёт накладные расходы на проверку типов в рантайме. JIT-компилятор, добавленный в **PHP 8.0**, частично компенсирует этот разрыв для вычислительно интенсивных задач.

## Основные типы данных

PHP поддерживает **10 примитивных типов**:

| Группа | Типы |
|---|---|
| **Скалярные (4)** | `bool`, `int`, `float` (aka `double`), `string` |
| **Составные (4)** | `array`, `object`, `callable`, `iterable` |
| **Особые (2)** | `resource`, `null` |

**Псевдотипы** (для удобства чтения): `mixed`, `void`, `never`.

### Скалярные типы

- **`bool`** — `true` или `false`.
- **`int`** — целые числа: `1`, `0`, `-5`.
- **`float`** — числа с плавающей запятой: `1.5`, `-0.05`, `3.14`.
- **`string`** — последовательность символов в одинарных или двойных кавычках.

### Составные типы

- **`array`** — упорядоченная карта (не просто «список»).
- **`object`** — экземпляр класса.
- **`callable`** — то, что можно вызвать как функцию.
- **`iterable`** — то, что можно перебрать в `foreach`.

### Особые типы

- **`resource`** — внешний ресурс (открытый файл, соединение с БД). Нельзя создать вручную.
- **`null`** — отсутствие значения.

## Как узнать тип переменной

| Функция | Что возвращает | Рекомендация |
|---|---|---|
| `gettype($var)` | `"integer"`, `"double"`, `"string"` | Устаревшая (но работает) |
| `get_debug_type($var)` | `"int"`, `"float"`, `"string"` | **Рекомендуется в PHP 8+** |
| `var_dump($var)` | Тип + значение (рекурсивно) | Для отладки |
| `print_r($var)` | Только значение (читаемо) | Для массивов |
| `var_export($var)` | Валидный PHP-код | Для копирования в скрипт |

**Важно:** `gettype(3.14)` возвращает **`"double"`**, а не `"float"` — это историческое наследие. `get_debug_type()` возвращает каноническое `"float"`.

## Приведение типов

### Явное приведение (explicit cast)

Тип указывается в скобках:

```php
$int = (int) "123";       // 123
$float = (float) "12.5";  // 12.5
$string = (string) 42;    // "42"
$bool = (bool) 0;         // false
$array = (array) $object;
```

### Неявное приведение (implicit coercion / type juggling)

PHP сам преобразует тип в зависимости от контекста:

```php
$sum = 1 + "2";   // 3 (строка преобразована в число)
```

### Правила приведения к `bool`

В `false` преобразуются:

```text
false, 0, 0.0, "", "0", [], null
```

Всё остальное — `true`. Обрати внимание: строка `"0"` ложна, а `"0.0"` — истинна (непустая строка).

### Правила приведения к числу

```php
(int) "123abc";    // 123
(int) "abc123";    // 0
(float) "12.5abc"; // 12.5
```

Начиная с PHP 8.0, нечисловая строка в числовом контексте вызывает `TypeError` (для внутренних функций) или `Warning`.

## Строгий режим (`strict_types`)

Директива `declare(strict_types=1);` включает строгую проверку типов. Она должна быть первой инструкцией в файле (после `<?php`) и действует только на текущий файл.

Без строгого режима PHP неявно приводит скалярные типы. Со строгим режимом принимается только точное соответствие.

Единственное исключение: `int` может быть передан в параметр, ожидающий `float` (потому что `float` — надмножество целых). Обратное не работает: `float` в `int`-параметр вызовет `TypeError`.

```php
declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}

add(1, 2);      // OK
add(1.5, 2);    // TypeError
add("1", 2);    // TypeError
```
