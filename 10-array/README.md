Этот урок — туториал по работе с массивами в PHP 8.

## Что такое массив

Массив в PHP — это **упорядоченная карта** (ordered map), которая сопоставляет **ключи** и **значения**. Значения могут быть любого типа, включая другие массивы.

## Создание массива

```php
// Современный синтаксис (предпочтительный):
$arr = [1, 2, 3];
$arr = ['a' => 1, 'b' => 2];

// Старый синтаксис:
$arr = array(1, 2, 3);
```

## Ключи массива

- **Целочисленные ключи** — автоматически назначаются с нуля, если не указаны.
- **Строковые ключи** — задаются явно.
- **Отрицательные ключи** — допустимы как обычные целочисленные ключи (не являются доступом «с конца», в отличие от строк).

```php
$arr = ['a', 'b', 'c'];       // [0 => 'a', 1 => 'b', 2 => 'c']
$arr[] = 'd';                 // [3 => 'd']
$arr[-1] = 'x';               // [-1 => 'x'] — отдельный элемент
```

**Важно:** обратиться к последнему элементу через `$arr[-1]` нельзя, если ключ `-1` не задан явно.

## Доступ к элементам

```php
$arr = ['a', 'b', 'c'];
echo $arr[0];    // 'a'
echo $arr[2];    // 'c'
```

При обращении к неопределённому ключу:

- PHP 8.0+ выдаёт `Warning: Undefined array key`;
- возвращается `null`.

## Операции с массивами

### Добавление

```php
$arr[] = 'new';              // В конец
array_push($arr, 'a', 'b');  // В конец (несколько)
array_unshift($arr, 'first'); // В начало
```

### Удаление

```php
array_pop($arr);             // Удаляет и возвращает последний
array_shift($arr);           // Удаляет и возвращает первый (с переиндексацией)
unset($arr[1]);              // Удаляет по ключу (без переиндексации)
unset($arr);                 // Удаляет весь массив
```

### Просмотр

```php
var_dump($arr);   // Тип + значения
print_r($arr);    // Читаемый вид
count($arr);      // Количество элементов
```

## Ассоциативные массивы

Массивы с именованными ключами:

```php
$user = [
    'name' => 'Gio',
    'age' => 30,
    'email' => 'gio@example.com'
];

echo $user['name'];   // Gio
```

## Многомерные массивы

Массивы внутри массивов:

```php
$matrix = [
    ['яблоко', 'банан'],
    ['груша', 'слива']
];

echo $matrix[0][1];   // 'банан'
```

## Безопасный доступ

| Способ | Ключ есть, значение `null` | Ключа нет |
| --- | --- | --- |
| `isset($arr['k'])` | `false` | `false` |
| `array_key_exists('k', $arr)` | `true` | `false` |
| `$arr['k'] ?? 'default'` | `null` (не сработает) | `'default'` |

```php
if (isset($users['admin']['name'])) { ... }
if (array_key_exists('age', $user)) { ... }
$name = $users['unknown']['name'] ?? 'Аноним';
```

## Деструктуризация (PHP 7.1+)

```php
[$a, $b] = [1, 2];
[, $second] = [1, 2];
['name' => $n, 'age' => $a] = ['name' => 'Gio', 'age' => 30];
[$a, [$b, $c]] = [1, [2, 3]];
```

## Оператор spread `...` (PHP 7.4+, строковые ключи с 8.1)

```php
$a = [1, 2];
$b = [3, 4];
$merged = [...$a, ...$b];   // [1, 2, 3, 4]

// PHP 8.1+ — строковые ключи:
$arr = [...['a' => 1], ...['a' => 2, 'b' => 3]];   // ['a' => 2, 'b' => 3]
```

Отличие от `array_merge()`: spread — языковая конструкция, работает быстрее. Отличие от `+`: spread перезаписывает дубликаты строковых ключей, а `+` — оставляет первый.

## Основные функции

| Функция | Описание |
| --- | --- |
| `count($arr)` | Количество элементов |
| `in_array($needle, $arr)` | Проверка значения |
| `array_key_exists($key, $arr)` | Проверка ключа |
| `array_keys($arr)` | Все ключи |
| `array_values($arr)` | Все значения |
| `array_merge($a, $b)` | Слияние |
| `array_map($fn, $arr)` | Применить функцию ко всем |
| `array_filter($arr, $fn)` | Фильтрация |
| `array_reduce($arr, $fn, $init)` | Свёртка |
| `sort($arr)` / `rsort($arr)` | Сортировка по значению |
| `array_slice($arr, $offset, $len)` | Часть массива |

```php
$numbers = [1, 2, 3, 4, 5];

$squared = array_map(fn($n) => $n * $n, $numbers);
$even = array_filter($numbers, fn($n) => $n % 2 === 0);
$sum = array_reduce($numbers, fn($carry, $n) => $carry + $n, 0);
```

## Изменения в PHP 8.1+

- `$GLOBALS` — доступ как к массиву ограничен.
- Автоматическое преобразование `false` в массив — deprecated.
- Распаковка массивов со строковыми ключами — поддерживается.
