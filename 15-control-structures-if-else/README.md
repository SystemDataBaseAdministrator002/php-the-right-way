# Условные операторы: if, else, elseif

> Учебное пособие по PHP 8 · [Видеоурок](https://www.youtube.com/watch?v=PUWrc6vzRMw&list=PLr3d3QYzkw2xabQRUpcZ_IBk9W50M9pe-&index=16&pp=iAQB)

Этот урок — туториал по условным операторам в PHP 8.

## Синтаксис `if`

`if` выполняет блок кода, если условие истинно (`true`).

```php
if ($condition) {
    // выполнится, если $condition == true
}
```

**Рекомендация:** всегда используй фигурные скобки `{}`, даже для одной инструкции — это улучшает читаемость и предотвращает ошибки.

---

## `else`

Если условие ложно, выполняется блок `else`:

```php
if ($isPaid) {
    echo 'Оплачено';
} else {
    echo 'Не оплачено';
}
```

---

## `elseif`

Для проверки нескольких условий используется `elseif`:

```php
$score = 85;

if ($score >= 90) {
    echo 'A';
} elseif ($score >= 80) {
    echo 'B';
} elseif ($score >= 70) {
    echo 'C';
} else {
    echo 'F';
}
```

Условия проверяются по порядку, срабатывает первая подходящая ветка.

---

## Вложенные условия

```php
if ($user) {
    if ($user->isAdmin()) {
        echo 'Админ';
    } else {
        echo 'Пользователь';
    }
}
```

---

## Условие как выражение

Условие может быть любым выражением, приводящимся к `bool`:

```php
if ($count) { ... }          // 0 → false
if (count($arr)) { ... }     // пустой массив → false
if ($user->isActive()) { ... }
if ($a > 5 && $b < 10) { ... }
```

---

## `elseif` vs `else if`

В обычном синтаксисе оба варианта работают:

```php
if ($a) { ... } elseif ($b) { ... }
if ($a) { ... } else if ($b) { ... }
```

В альтернативном синтаксисе — только `elseif` (слитно).

---

## Альтернативный синтаксис

Используется для встраивания PHP в HTML. Вместо `{}` — двоеточие и `endif;`.

```php
<?php if ($isAdmin): ?>
    <p>Панель администратора</p>
<?php else: ?>
    <p>Обычная страница</p>
<?php endif; ?>
```

**Правила:**

- После `if`, `elseif`, `else` — двоеточие.
- `elseif` пишется слитно (`else if` вызовет ошибку).
- Завершение — `endif;` (с точкой с запятой).
- Можно смешивать HTML и PHP.
- Нельзя смешивать `{}` и альтернативный синтаксис в одной конструкции.

**Пример с HTML:**

```php
<div class="user-card">
    <?php if ($user->isOnline()): ?>
        <span class="status online">Онлайн</span>
    <?php elseif ($user->lastSeen() > time() - 3600): ?>
        <span class="status recent">Был недавно</span>
    <?php else: ?>
        <span class="status offline">Офлайн</span>
    <?php endif; ?>

    <h3><?= htmlspecialchars($user->getName()) ?></h3>
</div>
```

---

## Тернарный оператор (краткая форма)

```php
$status = $isPaid ? 'paid' : 'unpaid';
```

---

## Когда использовать

- **Альтернативный синтаксис** — в файлах представлений (views/templates), где много HTML.
- **Классический синтаксис** — в контроллерах, моделях, хелперах, служебных файлах.
