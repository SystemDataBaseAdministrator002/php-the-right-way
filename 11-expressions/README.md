# Выражения в PHP 8

> Учебное пособие по PHP 8 · [Видеоурок](https://www.youtube.com/watch?v=bPntels5hw8&list=PLr3d3QYzkw2xabQRUpcZ_IBk9W50M9pe-&index=12&pp=iAQB)

Этот урок — туториал о выражениях в PHP 8: что это такое и как они вычисляются.

## Что такое выражение

**Выражение** — это всё, что имеет значение. В PHP почти всё является выражением.

Официальное определение: «anything that has a value».

Простейшие формы выражений:

- **Литералы** — `5`, `"Hello"`, `3.14`, `true`.
- **Переменные** — `$a`, `$name`.
- **Константы** — `PHP_VERSION`, `SITE_NAME`.

```php
$a = 5;   // 5 — выражение со значением 5
$b = $a;  // $a — выражение со значением 5
```

## Присваивание — это выражение

Присваивание `$a = 5` — это выражение, значением которого является присвоенное значение (в данном случае `5`).

Это позволяет:

```php
$b = $a = 5;            // $a = 5, $b = 5
$c = ($a = 5) + 2;      // $a = 5, $c = 7
```

Присваивания разбираются справа налево: `$b = $a = 5` эквивалентно `$a = 5; $b = 5;`.

## Функции — это выражения

Значение функции — её возвращаемое значение:

```php
function foo(): int {
    return 5;
}

$c = foo();   // $c = 5
```

`strlen("abc")` возвращает `int(3)` — это выражение.

## Инкремент и декремент как выражения

```php
$a = 5;
$b = $a++;   // $b = 5, $a = 6 (постфиксный возвращает старое значение)
$c = ++$a;   // $a = 7, $c = 7 (префиксный возвращает новое значение)
```

## `print` vs `echo`

- `print` — выражение, возвращает `1`.
- `echo` — не выражение, ничего не возвращает.

```php
$result = print 'Hello';   // $result = 1
// $result = echo 'Hello'; // Синтаксическая ошибка
```

## Тернарный оператор и `match`

```php
$status = $isPaid ? 'paid' : 'unpaid';           // Тернарный оператор
$status = match ($isPaid) {                       // match (PHP 8.0)
    true  => 'paid',
    false => 'unpaid',
};
```

## Типы значений выражений

Значение выражения может быть любого типа:

| Категория | Типы |
| --- | --- |
| **Скалярные** | `bool`, `int`, `float`, `string` |
| **Составные** | `array`, `object` |
| **Специальные** | `null`, `resource` |

```php
$x = 5;                    // int
$name = "Alice";           // string
$isValid = ($age >= 18);   // bool
$numbers = [10, 20, 30];   // array
$car = new Car();          // object
$db = mysqli_connect(...); // resource
$none = null;              // null
```

## Выражение vs оператор

- **Выражение** — то, что имеет значение: `5`, `$a`, `foo()`, `$a = 5`, `$a++`.
- **Оператор** (statement) — инструкция, которая выполняется: `if (...) { ... }`, `while (...) { ... }`, `echo ...`.

Выражение может быть оператором (если завершить `;`), но не наоборот.

## Приоритет и ассоциативность (кратко)

```php
echo 1 + 5 * 3;   // 16, а не 18 — потому что * выше +
echo (1 + 5) * 3; // 18 — скобки меняют приоритет
```

## Важные нюансы

- Тип значения выражения определяется в момент вычисления.
- PHP — динамически типизированный язык: тип переменной может меняться.
- Операторы сравнения (`==`, `<`, `>`) и логические (`&&`, `||`, `!`) возвращают `bool`.
- Операторы `??`, `?:`, `match` возвращают значения произвольного типа.
