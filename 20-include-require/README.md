# Включение файлов: include, require, include_once, require_once

> Учебное пособие по PHP 8 · [Видеоурок](https://www.youtube.com/watch?v=pQLO6l5lp-Y&list=PLr3d3QYzkw2xabQRUpcZ_IBk9W50M9pe-&index=21&pp=iAQB)

Этот урок — туториал по включению файлов в PHP 8.

## Языковые конструкции

`include`, `require`, `include_once`, `require_once` — **языковые конструкции**, а не функции. Их нельзя передать как callable.

## Разница между `include` и `require`

| | `include` | `require` |
| --- | --- | --- |
| При отсутствии файла | `Warning`, продолжение | `Fatal error`, остановка |
| Для чего | Шаблоны, частичные файлы | Критические зависимости (библиотеки, конфиги) |

```php
// Предупреждение, скрипт продолжит работу:
include 'nonexistent.php';

// Фатальная ошибка, скрипт остановится:
require 'nonexistent.php';
```

---

## `_once`-версии

`include_once` и `require_once` включают файл только один раз, даже если инструкция встречается несколько раз. Это предотвращает повторное объявление функций и классов.

```php
require_once 'functions.php';
require_once 'functions.php';   // Файл не будет включён повторно
```

Когда использовать:

| Ситуация | Инструкция |
| --- | --- |
| Библиотека функций / классы | `require_once` |
| Конфигурация | `require_once` |
| Шаблон (header, footer) | `include` |
| Частичный шаблон в цикле | `include` |

**Важно:** для частичных шаблонов, которые могут выводиться несколько раз, нельзя использовать `_once` — иначе повторный вывод не сработает.

## Что возвращают инструкции

`include` возвращает:

- `false` при сбое;
- `1` при успешном выполнении;
- значение `return` из подключаемого файла (если оно есть).

Пример с конфигом:

```php
// config.php
return [
    'db_host' => 'localhost',
    'db_name' => 'app',
];

// index.php
$config = include __DIR__ . '/config.php';
echo $config['db_host'];   // localhost
```

## Пути включения

Порядок поиска файла:

1. Абсолютный путь (если указан).
2. `include_path` (если путь не начинается с `./` или `../`).
3. Директория вызывающего скрипта (`__DIR__`).
4. Текущая рабочая директория (`getcwd()`).

**Рекомендация:** используй `__DIR__` для надёжных путей:

```php
// Ненадёжно (зависит от текущей директории):
include 'partials/header.php';

// Надёжно:
include __DIR__ . '/partials/header.php';
```

## Буферизация вывода

`ob_start()` и `ob_get_clean()` позволяют «поймать» вывод `include` и обработать его как строку.

Пошагово:

1. `ob_start()` — запускает буфер. Весь вывод (`echo`, HTML) идёт в память, а не в браузер.
2. `include 'partial.php'` — вывод из файла попадает в буфер.
3. `ob_get_clean()` — возвращает содержимое буфера как строку и отключает буферизацию.

Пример:

```php
$title = 'Заголовок';
$text = 'Текст';

ob_start();
include __DIR__ . '/partial.php';
$html = ob_get_clean();

// Модифицируем строку:
$html = str_replace('card', 'card highlighted', $html);

echo $html;
```

Применение:

- Модификация вывода (замена текста, классов).
- Рендер в переменную (для JSON, писем, кэша).
- Тестирование и изоляция.

Callback в `ob_start()`:

```php
ob_start(function ($buffer) {
    return preg_replace('/\s+/', ' ', $buffer);   // Минификация
});
include 'partial.php';
$html = ob_get_clean();
```

## Практическое применение

Структурирование кода — разбивка на файлы.

Переиспользование — общие функции, классы, конфиги.

HTML-шаблоны — вынос повторяющихся фрагментов (навигация, footer).

Пример с шаблоном:

```php
// header.php
<header>
    <nav>...</nav>
</header>

// index.php
<?php include __DIR__ . '/partials/header.php'; ?>
<main>...</main>
```

## Область видимости

`include` выполняется в области видимости вызывающего кода. Переменные, определённые в подключаемом файле, становятся доступны в вызывающем файле.

```php
// partial.php
$message = 'Hello from partial';

// index.php
include 'partial.php';
echo $message;   // Hello from partial
```

---

## Важные нюансы

- `include` / `require` — языковые конструкции, а не функции.
- Используй `__DIR__` для надёжных путей.
- Для библиотек и конфигов — `require_once`.
- Для шаблонов — `include` (без `_once`).
- `include` работает с файлами любого расширения.
