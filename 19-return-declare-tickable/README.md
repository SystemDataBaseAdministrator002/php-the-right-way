# Оператор return и директива declare

> Учебное пособие по PHP 8 · [Видеоурок](https://www.youtube.com/watch?v=6cPc_SEfgSw&list=PLr3d3QYzkw2xabQRUpcZ_IBk9W50M9pe-&index=20&pp=iAQB)

Этот урок — туториал по операторам `return`, `declare` и tickable statements.

## Оператор `return`

### Внутри функции

`return` немедленно завершает выполнение функции и возвращает управление в точку вызова:

```php
function add(int $a, int $b): int
{
    return $a + $b;
    // Код после return не выполнится
}

$result = add(2, 3);   // $result = 5
```

Если выражение не указано, функция возвращает `null`:

```php
function doNothing()
{
    return;
}

var_dump(doNothing());   // NULL
```

### Вне функции (глобальная область)

`return` завершает выполнение текущего файла:

- Если файл — главный скрипт, выполнение скрипта прекращается.
- Если файл подключён через `include`/`require`, управление возвращается в файл-родитель, а значение `return` становится значением `include`.

Пример:

```php
// helper.php
echo "Начало helper.php\n";
return 42;
echo "Эта строка не выполнится\n";
```

```php
// index.php
$value = include 'helper.php';
echo "Значение: $value\n";   // 42
echo "Продолжение index.php\n";
```

Вывод:

```text
Начало helper.php
Значение: 42
Продолжение index.php
```

### В `eval()`

`return` также завершает выполнение `eval()`:

```php
$result = eval('return 42;');
echo $result;   // 42
```

### Сводная таблица

| Контекст | Что завершается | Возвращаемое значение |
|---|---|---|
| Функция | Только функция | Значение функции |
| Файл (главный) | Весь скрипт | — |
| Файл (через `include`) | Файл | Значение для `include` |
| `eval()` | `eval()` | Значение для `eval()` |

## Директива `declare`

`declare` задаёт директивы выполнения для блока кода. Синтаксис:

```php
declare(directive) statement
```

или с блоком:

```php
declare(ticks=1) {
    // Код
}
```

Директивы вычисляются на этапе компиляции, поэтому принимают только литеральные значения (нельзя использовать переменные или константы).

### Директива `strict_types`

Включает строгую проверку типов:

```php
declare(strict_types=1);

function add(int $a, int $b): int
{
    return $a + $b;
}

add(1, 2);       // OK
add("1", 2);     // TypeError
```

Правила:

- Должна быть первой инструкцией в файле (после `<?php`).
- Действует только в текущем файле. Если функция объявлена в файле со `strict_types`, но вызвана из файла без него — проверка не сработает.
- Не влияет на внутренние функции PHP.

### Директива `encoding`

Задаёт кодировку скрипта:

```php
declare(encoding='UTF-8');
```

Статус: на практике почти не используется, так как работает только при сборке PHP с `--enable-zend-multibyte`. При использовании с `namespace` допустима только форма без блока `{}`.

### Директива `ticks` (устарела)

⚠️ **Важно:** `ticks` объявлены устаревшими с PHP 5.3.0 и планируются к удалению в PHP 9.0. В новом коде использовать не рекомендуется.

`ticks` позволяют выполнять функцию через каждые N низкоуровневых операторов:

```php
declare(ticks=1);

function tickHandler(): void
{
    echo "Tick!\n";
}

register_tick_function('tickHandler');

$a = 1;       // Tick
$b = 2;       // Tick
echo $a + $b; // Tick
```

- `ticks=N` — функция вызывается каждые N операторов.
- `register_tick_function()` — регистрирует функцию-обработчик.
- `unregister_tick_function()` — снимает регистрацию.

Статус:

| Версия | Статус |
|---|---|
| PHP 5.3 | Устарели |
| PHP 8.x | Работают, но не рекомендуются |
| PHP 9.0 | Планируются к удалению |

## Краткие итоги

- `return` — завершает функцию, файл или `eval()`, возвращая значение.
- `strict_types` — строгая проверка типов, только в текущем файле.
- `encoding` — кодировка скрипта, почти не используется.
- `ticks` — устарели, не использовать в новом коде.

## Практика

Создай файл `index.php` и выполни задания:

1. Напиши функцию `greet(string $name): string`, которая возвращает приветствие. Если имя пустое — верни `null` (сделай тип `?string`).
2. Создай файл `config.php`, который через `return` возвращает массив с настройками. Подключи его через `include` в `index.php` и выведи значения.
3. Включи `strict_types` в `index.php`. Вызови функцию из задания 1 со строковым аргументом `"42"` (числовой) — убедись, что `TypeError` не возникает. Попробуй передать `float` — проверь поведение.
4. Напиши функцию `divide(int $a, int $b): float`, которая возвращает результат деления. Если `b === 0` — верни `0.0` через `return` (без исключения).
5. Напиши скрипт с `declare(ticks=1)`, зарегистрируй обработчик через `register_tick_function` и выведи количество тиков после выполнения 5 операций.
6. Создай два файла: в первом — функция с `strict_types`, во втором — её вызов без `strict_types`. Передай `string` вместо `int` и проверь, сработает ли строгое правило.
7. Напиши функцию `findUser(array $users, int $id): ?array`, которая ищет пользователя по `id` и возвращает массив или `null`. Используй `return` внутри цикла.
8. Создай файл `bootstrap.php`, который через `return` возвращает `true`, если все проверки пройдены, и `false` — если нет. Подключи его в `index.php` и выведи результат.

```text
Удачи! Если застрял — пересмотри урок про функции и область видимости.
```
