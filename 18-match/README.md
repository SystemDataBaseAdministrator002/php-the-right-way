# Выражение match в PHP 8

> Учебное пособие по PHP 8 · [Видеоурок](https://www.youtube.com/watch?v=jCUyvHUKSmE&list=PLr3d3QYzkw2xabQRUpcZ_IBk9W50M9pe-&index=19&pp=iAQB)

Этот урок — туториал по выражению `match` в PHP 8 и его сравнению с `switch`.

## Что такое `match`

`match` — это **выражение**, введённое в **PHP 8.0**. Оно сравнивает значение с набором условий и возвращает результат первого совпадения.

```php
$result = match ($status) {
    'paid'     => 'Оплачено',
    'pending'  => 'Ожидает',
    'refunded' => 'Возврат',
    default    => 'Неизвестно',
};
```

## Ключевые отличия от `switch`

| Характеристика | `switch` | `match` |
| --- | --- | --- |
| Тип | Оператор | Выражение |
| Возвращает значение | Нет | Да |
| Требует `break` | Да | Нет (нет fall-through) |
| Сравнение | Нестрогое (`==`) | Строгое (`===`) |
| `default` обязателен | Нет | Да (если не все случаи покрыты) |
| Множественные операторы в ветке | Да | Нет (только одно выражение) |
| Объединение условий через запятую | Нет | Да |

## Строгое сравнение

`match` использует `===`, поэтому `1` и `'1'` — разные значения:

```php
$value = '1';

$result = match ($value) {
    1       => 'Число 1',
    '1'     => 'Строка "1"',
    default => 'Не совпало',
};

echo $result;   // Строка "1"
```

## Объединение условий

Несколько значений можно перечислить через запятую:

```php
$result = match ($x) {
    1, 2, 3 => 'маленькое число',
    4, 5    => 'среднее',
    default => 'большое',
};
```

## `match` как выражение

`match` можно использовать в любом контексте, где ожидается значение:

```php
echo match ($status) {
    'paid'    => 'Оплачено',
    default   => 'Неизвестно',
};

$message = 'Статус: ' . match ($status) {
    'paid'    => 'Оплачено',
    default   => 'Неизвестно',
};
```

## Исчерпывающий характер

`match` должен покрыть все возможные значения либо явно, либо через `default`. Если совпадений нет и `default` отсутствует, выбрасывается `UnhandledMatchError` (подкласс `Error`, PHP 8.0).

```php
$value = 3;

$result = match ($value) {
    1 => 'one',
    2 => 'two',
};
// UnhandledMatchError: No matching case and no default case
```

Безопасный вариант:

```php
$result = match ($value) {
    1       => 'one',
    2       => 'two',
    default => 'unknown',
};
```

## `default` с выбросом исключения

Если «неучтённый» случай — это ошибка логики, можно выбросить исключение:

```php
$status = match ($code) {
    200     => 'ok',
    404     => 'not found',
    default => throw new InvalidArgumentException('Unknown status code'),
};
```

## Ограничения

- **Только одно выражение в ветке.** В отличие от `switch`, где можно выполнить несколько операторов, в `match` каждая ветка — одно выражение.
- **Нет fall-through.** `break` не нужен и не используется.
- **`default` может быть в любом месте**, но по стилю его ставят последним.

## `match` с enum (PHP 8.1+)

Если `match` покрывает все случаи enum, `default` не нужен:

```php
enum Status {
    case Paid;
    case Pending;
    case Refunded;
}

$result = match ($status) {
    Status::Paid     => 'Оплачено',
    Status::Pending  => 'Ожидает',
    Status::Refunded => 'Возврат',
};
```

## Когда использовать `match`

- Когда нужно вернуть значение на основе условия.
- Когда важна строгая проверка типов.
- Когда нужна краткость и читаемость.
- Когда все случаи известны и должны быть покрыты.

## Когда использовать `switch`

- Когда в ветках нужно выполнить несколько операторов.
- Когда нужна гибкость с fall-through (намеренным).
- Когда сравнение должно быть нестрогим.
