Этот урок — туториал по областям видимости переменных и статическим переменным.

## Области видимости

В PHP две основные области видимости:

- **Глобальная** — переменные доступны в любом месте скрипта.
- **Локальная** — переменные доступны только внутри функции.

```php
$globalVar = 'global';

function test(): void
{
    $localVar = 'local';
    // $globalVar здесь недоступна
}
```

Важно: `include` и `require` наследуют область видимости вызывающего кода. Если `include` внутри функции — подключаемый файл видит только локальные переменные функции.

```php
$globalVar = 'global';

function test(): void
{
    include 'file.php';   // file.php не увидит $globalVar
}
```

## Доступ к глобальным переменным внутри функции

### 1. Ключевое слово `global`

```php
$name = 'Tom';

function hello(): void
{
    global $name;
    echo "Hello, $name";
}

hello();   // Hello, Tom
```

Можно объявить несколько переменных через запятую:

```php
global $var1, $var2, $var3;
```

### 2. Суперглобальный массив `$GLOBALS`

`$GLOBALS` — ассоциативный массив всех глобальных переменных. Ключ — имя переменной (без `$`). Доступен в любой области видимости без объявления.

```php
$name = 'Tom';

function changeName(): void
{
    $old = $GLOBALS['name'];
    echo "Старое имя: $old<br>";

    $GLOBALS['name'] = 'Tomas';
}

changeName();
echo "Новое имя: $name";   // Новое имя: Tomas
```

Ограничение в PHP 8.1+: некоторые операции с `$GLOBALS` как с массивом запрещены:

```php
// PHP 8.1+: ошибка
array_pop($GLOBALS);
```

### 3. Передача через параметры (рекомендуется)

```php
$name = 'Tom';

function hello(string $userName): void
{
    echo "Hello, $userName";
}

hello($name);   // Hello, Tom
```

Этот способ делает функции предсказуемыми, изолированными и пригодными для тестирования.

### Рекомендации

- Избегай `global` и `$GLOBALS` — они усложняют отладку, тестирование и поддержку.
- Предпочитай параметры и возвращаемые значения.
- `$GLOBALS` всегда доступен, `global` требует явного объявления.

## Статические переменные

Статическая переменная — локальная переменная, которая не уничтожается после выхода из функции и сохраняет значение между вызовами.

```php
function counter(): int
{
    static $count = 0;
    $count++;
    return $count;
}

echo counter();   // 1
echo counter();   // 2
echo counter();   // 3
```

Использование для кэширования:

```php
function expensiveOperation(): array
{
    static $cache = null;

    if ($cache === null) {
        $cache = computeExpensiveData();
    }

    return $cache;
}
```

Ограничения:

- До PHP 8.3 инициализация — только константное выражение.
- В PHP 8.3+ разрешены произвольные выражения.
- Статические переменные не наследуются.
- Существуют только в функциях и методах.

---

## Краткие итоги

- **Глобальная область** — весь скрипт, **локальная** — только функция.
- `global` — доступ к глобальной переменной внутри функции.
- `$GLOBALS` — суперглобальный массив, доступен всегда.
- **Параметры** — рекомендуемый способ передачи данных.
- `static` — сохранение значения между вызовами функции.
