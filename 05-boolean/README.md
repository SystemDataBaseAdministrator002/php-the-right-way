# Логический тип (Boolean)

Этот урок — туториал по логическому типу данных в PHP 8.

## Что такое логический тип

Логическое значение выражает истинность и может быть только `true` или `false`. Эти константы **нечувствительны к регистру**: `true`, `TRUE`, `True` — всё допустимо. Автор рекомендует придерживаться единого стиля — например, только строчные буквы.

Логические значения применяются в структурах управления: `if`, `while`, `for`, тернарных операторах.

---

## Какие значения приводятся к `false`

При преобразовании к `bool` (явном или неявном) следующие значения считаются `false`:

| Значение | Пример |
| --- | --- |
| `false` (само по себе) | `false` |
| Целое `0` | `0`, `-0` |
| Float `0.0` и `-0.0` | `0.0`, `-0.0` |
| Пустая строка | `""` |
| Строка `"0"` | `"0"` |
| Пустой массив | `[]` |
| `null` (включая неинициализированные переменные) | `null` |

**Всё остальное считается `true`**, в том числе:

- отрицательные числа, не равные нулю (`-1`, `-0.5`);
- непустые строки (`"false"`, `"0.0"`, `" "`);
- непустые массивы;
- ресурсы;
- объекты (кроме специальных, например `SimpleXML` без атрибутов);
- **`NAN`** (не-число).

**Важно:** `true` и `false` — не числа `1` и `0`. Они преобразуются в них при выводе или в арифметическом контексте, но являются отдельным типом.

---

## Как вывести логическое значение

1. **Через `var_dump()`** — покажет тип и значение (`bool(true)` или `bool(false)`).
2. **Через `echo` / `print`** — PHP преобразует значение в строку:
   - `true` → `"1"`
   - `false` → `""` (пустая строка)

```php
var_dump(true);    // bool(true)
echo true;         // 1
echo false;        // (ничего)
```

---

## Проверка типа

- `var_dump($var)` — показывает тип и значение.
- `is_bool($var)` — возвращает `true`, если переменная логического типа, иначе `false`.

```php
$var = true;
var_dump(is_bool($var));   // bool(true)
```

---

## Особенность строки `"false"`

Строка `"false"` оценивается как `true`, потому что она не пустая и не равна `"0"`. Это частая ловушка:

```php
var_dump((bool) "false");   // bool(true)
var_dump((bool) "");        // bool(false)
var_dump((bool) "0");       // bool(false)
var_dump((bool) "0.0");     // bool(true) — непустая строка!
```

## Преобразование `bool` в строку

| Способ | `true` → | `false` → | Примечание |
| --- | --- | --- | --- |
| `(string)` | `"1"` | `""` | Просто, но `false` даёт пустую строку |
| `strval()` | `"1"` | `""` | Аналог `(string)` |
| `var_export($bool, true)` | `"true"` | `"false"` | Канонические строки |
| `json_encode($bool)` | `"true"` | `"false"` | Для JSON |
| Тернарный оператор | `"true"` | `"false"` | Полный контроль |
| `match` (PHP 8) | `"true"` | `"false"` | Современный подход |
| `sprintf()` | зависит от формата | зависит от формата | Гибко, но избыточно |

Примеры:

```php
// (string)
$s = (string) true;      // "1"
$s = (string) false;     // ""

// var_export
$s = var_export(true, true);   // "true"

// Тернарный оператор
$s = $bool ? 'true' : 'false';

// match (PHP 8)
$s = match ($bool) {
    true  => 'true',
    false => 'false',
};

// json_encode
$s = json_encode(true);   // "true"
```

**Рекомендация:** для отладки и логирования используй `var_export($value, true)` — он даёт однозначное представление. Для пользовательского вывода — тернарный оператор или `match`.

## Преобразование строк в `bool`

Стандартный способ — `filter_var()`:

```php
filter_var('true', FILTER_VALIDATE_BOOLEAN);    // true
filter_var('false', FILTER_VALIDATE_BOOLEAN);   // false
filter_var('on', FILTER_VALIDATE_BOOLEAN);      // true
filter_var('off', FILTER_VALIDATE_BOOLEAN);     // false
filter_var('yes', FILTER_VALIDATE_BOOLEAN);     // true
filter_var('no', FILTER_VALIDATE_BOOLEAN);      // false
```

С флагом `FILTER_NULL_ON_FAILURE` возвращает `null` для нераспознанных значений.

---

## Дополнительные функции

- `boolval($value)` — аналог `(bool)`.
- `settype($var, 'bool')` — изменяет тип переменной на месте.
- `!!$value` — идиоматическое двойное отрицание для приведения к `bool`.
