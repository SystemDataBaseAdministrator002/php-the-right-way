# Тип данных Integer в PHP 8

> Учебное пособие по PHP 8 · [Видеоурок](https://www.youtube.com/watch?v=rjEP_GUdg6o&list=PLr3d3QYzkw2xabQRUpcZ_IBk9W50M9pe-&index=7&pp=iAQB)

Этот урок — туториал по типу данных `integer` в PHP 8.

## Что такое целые числа

Целые числа — это числа без десятичных знаков (например, `1`, `2`, `3`, `0`, `-5`). Множество целых чисел: ℤ = {..., -2, -1, 0, 1, 2, ...}.

Размер `int` зависит от платформы:

| Платформа | `PHP_INT_MAX` | `PHP_INT_SIZE` |
| --- | --- | --- |
| 32-бит | `2147483647` | `4` |
| 64-бит | `9223372036854775807` | `8` |

Проверить диапазон можно константами `PHP_INT_MAX`, `PHP_INT_MIN` и `PHP_INT_SIZE`. `PHP_INT_MIN` доступна с **PHP 7.0.0**, остальные — раньше.

## Системы счисления

Целые числа можно указывать в разных системах:

- **десятичная** (основание 10): `1234`
- **шестнадцатеричная** (`0x`): `0x1A` = 26
- **восьмеричная** (`0` или `0o`): `0123` = 83, `0o123` = 83 (PHP 8.1+)
- **двоичная** (`0b`): `0b11111111` = 255

**Совет:** используй `0o` для восьмеричных чисел, чтобы не путать их с десятичными.

## Переполнение целого числа

Если значение выходит за пределы `int`, PHP автоматически преобразует его в `float`:

```php
var_dump(PHP_INT_MAX + 1);   // float(9.2233720368548E+18)
```

## Преобразование в int

### Правила

- `true` → `1`
- `false` → `0`
- `float` → округление в сторону нуля: `(int) 5.98` → `5`, `(int) -5.98` → `-5`
- `float` `INF`, `-INF`, `NAN` → `0`
- числовая строка → целая часть: `(int) "5.9"` → `5`
- leading-numeric строка → числовая часть: `(int) "87abc"` → `87`
- нечисловая строка → `0` (в PHP 8+ с предупреждением в арифметическом контексте)
- `null` → `0`

### Способы приведения

| Способ | Синтаксис | Особенности |
| --- | --- | --- |
| Приведение типа | `(int) $value` | Стандартный подход |
| `intval()` | `intval($value)` | Явное преобразование |
| `intval()` с base | `intval('FF', 16)` | Для строк в разных системах |
| Унарный плюс | `+$value` | Кратко, но менее очевидно |
| Арифметика | `$value + 0` | Не рекомендуется |

**Рекомендация:** используй `(int)` или `intval()` для читаемости.

## Проверка типа

- `is_int($var)` — `true`, если переменная целого типа
- `is_integer($var)` — алиас `is_int()`
- `is_long($var)` — алиас `is_int()`

## Подчёркивания в числах (PHP 7.4+)

Начиная с PHP 7.4.0, в числовых литералах можно использовать `_` для читаемости:

```php
$population = 1_000_000;
$bytes = 0xFF_FF_FF;
```

Подчёркивания удаляются сканером PHP на этапе парсинга. Это литералы, а не строки:

```php
var_dump(1_000);         // int(1000)
var_dump((int) "1_000"); // int(1) — потому что _ не числовой символ
```

## Дополнительно

Арифметика и тип результата:

```php
var_dump(4 * 2.5);   // float(10)
var_dump(10 / 2);    // int(5)
var_dump(10 / 3);    // float(3.333...)
```

Валидация через `filter_var()`:

```php
filter_var('123', FILTER_VALIDATE_INT);      // 123
filter_var('123abc', FILTER_VALIDATE_INT);   // false
```
