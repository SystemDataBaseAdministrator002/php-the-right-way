Этот урок — туториал по базовому синтаксису PHP 8.

## Работа с файлами и теги PHP

Чтобы файл интерпретировался как PHP, его расширение должно быть `.php`. PHP-код помещают между открывающим (`<?php`) и закрывающим (`?>`) тегами.

Если файл содержит только PHP-код, закрывающий тег **рекомендуется опускать**. Это предотвращает случайный вывод пробелов и переводов строк после `?>`, которые могут нарушить отправку HTTP-заголовков (ошибка «Headers already sent»). PSR-12 прямо предписывает опускать `?>` в файлах с чистым PHP.

Также существует сокращённый тег вывода `<?= ... ?>`, который всегда доступен и эквивалентен `<?php echo ...; ?>`. Он удобен для встраивания в HTML.

## Вывод данных и основы синтаксиса

Для вывода текста на экран используют `echo`. Например:

```php
echo "Hello World";
```

PHP — серверный язык: реальный код не отображается в браузере, браузер получает только результат выполнения.

Ключевые моменты синтаксиса:

- текст заключают в одинарные или двойные кавычки — так обозначают строку;
- операторы завершают точкой с запятой (есть исключения);
- закрывающий тег `?>` автоматически завершает последнее выражение, поэтому точка с запятой перед ним необязательна. Но если файл содержит только PHP-код и `?>` опущен — точка с запятой в последней строке обязательна;
- оператор `.` (точка) используется для конкатенации (склейки) строк: `'Hello' . ' ' . 'World'`.

## Языковые конструкции `echo` и `print`

`echo` и `print` — не функции, а языковые конструкции (language constructs). Они не являются функциями в том смысле, в каком являются `strlen()` или `var_dump()`, их нельзя передать как `callable`.

Отличия:

- `print` возвращает значение `1`, поэтому его можно использовать в выражениях. `echo` ничего не возвращает (тип `void`);
- с `echo` можно разделять запятыми несколько аргументов без скобок, с `print` — нельзя (только один аргумент);
- начиная с PHP 7.0 оба оператора компилируются в один и тот же опкод `ZEND_ECHO`. Разницы в производительности между ними нет. Утверждение «`echo` быстрее `print`» было актуально только до PHP 7.0.

## Переменные

Правила создания переменных в PHP:

- имя начинается с буквы или символа подчёркивания, но не с цифры;
- далее могут следовать буквы, цифры и подчёркивания;
- нельзя использовать специальные символы;
- некоторые имена зарезервированы — например, `$this` нельзя присваивать.

Переменные по умолчанию присваиваются по значению (копируется значение). Чтобы присвоить по ссылке (обе переменные указывают на одни данные), добавляют символ `&`:

```php
$a = 10;
$b = &$a;   // $b — ссылка на $a
$a = 20;
echo $b;    // 20
```

При использовании одинарных кавычек переменные внутри строки не подставляются — для этого нужны двойные кавычки. Можно заключать переменные в фигурные скобки для лучшей читаемости:

```php
$name = 'Gio';
echo "Hello, {$name}";   // Hello, Gio
echo 'Hello, $name';     // Hello, $name
```

## Встраивание PHP в HTML

PHP-код встраивают в HTML с помощью тегов `<?php ... ?>`. Можно выводить HTML-код прямо из PHP — например, для генерации динамического контента. Однако смешивать HTML и PHP в одном файле не всегда рекомендуется: это затрудняет чтение и поддержку. На практике шаблоны выносят в отдельные файлы.

---

## Комментарии

Способы добавления комментариев:

- **однострочный** — `//` или `#`;
- **многострочный** — `/* ... */`.

Важные нюансы:

- однострочный комментарий действует до конца строки или до закрывающего тега `?>`, что наступит раньше;
- нельзя вкладывать многострочные комментарии друг в друга — это вызовет ошибку;
- опасность досрочного закрытия: если внутри `/* ... */` встречается последовательность `*/`, комментарий закрывается досрочно, даже если вы этого не планировали. Это часто случается с путями или регулярными выражениями.

## Запуск PHP-скриптов

PHP-скрипты можно запускать двумя основными способами.

### Через браузер (веб-сервер)

Файл должен находиться в корне документа веб-сервера (`htdocs` в XAMPP). Откройте в браузере:

```text
http://localhost/php-the-right-way/02-basic-syntax/
```

Apache сам подставит `index.php`, если он есть в папке.

### Через командную строку (CLI)

1. Откройте терминал.
2. Перейдите в каталог с файлом:

   ```bash
   cd C:\xampp\htdocs\php-the-right-way\02-basic-syntax
   ```

3. Запустите файл:

   ```bash
   php index.php
   ```

Аргументы скрипта передаются после имени файла и доступны в скрипте через `$argv`. `$argv[0]` — имя скрипта, `$argv[1]` и далее — переданные аргументы. Количество аргументов (включая имя скрипта) доступно в `$argc`.

### Проверка работоспособности

Создайте тестовый файл:

```php
<?php
echo "PHP работает! Версия: " . PHP_VERSION . "\n";
```

Запустите:

```bash
php test.php
```

Если видите вывод с версией PHP — всё настроено верно.

### Дополнительно (для любопытных)

- `php -r '...'` — выполнить код без файла. PHP-теги не нужны.
- `php -f file.php` — явно указать файл (аналогично `php file.php`).
- `php -d memory_limit=256M script.php` — переопределить настройку `php.ini` на время выполнения.
- `php -n script.php` — игнорировать `php.ini`.
- `php -v` — проверить версию PHP.
