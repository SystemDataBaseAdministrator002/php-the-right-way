Этот урок — туториал по строковому типу данных, синтаксисам Heredoc и Nowdoc.

## Основы строк

Строка — это последовательность символов. Строкой считается значение в одинарных (`'`) или двойных (`"`) кавычках.

**Разница:**

- **Одинарные кавычки** — переменные не интерполируются, экранируются только `\'` и `\\`.
- **Двойные кавычки** — переменные интерполируются, поддерживаются escape-последовательности (`\n`, `\t`, `\r`, `\$` и т.д.).

```php
$name = 'Gio';
echo 'Hello, $name';    // Hello, $name
echo "Hello, $name";    // Hello, Gio
echo "Hello, {$name}";  // Hello, Gio (фигурные скобки для читаемости)
```

**PHP 8.3:** синтаксис интерполяции `${var}` объявлен устаревшим. Используй `{$var}`.

## Доступ к символам

Доступ к отдельным символам — через квадратные скобки с индексом от нуля:

```php
$str = 'Hello';
echo $str[0];    // 'H'
echo $str[4];    // 'o'
echo $str[-1];   // 'o' (PHP 7.1+, с конца)
```

Строки изменяемы:

```php
$str = 'Hello';
$str[0] = 'J';
echo $str;   // Jello
```

### Поведение за пределами строки

| Операция | Поведение |
| --- | --- |
| Чтение `$str[100]` | `Warning: Uninitialized string offset`, возвращает `""` |
| Запись `$str[100] = 'a'` | Строка дополняется пробелами до индекса 100 |

Раньше для доступа использовали `{}` (`$str{0}`), но:

- **PHP 7.4** — объявлено устаревшим.
- **PHP 8.0** — полностью удалено. Использование вызывает фатальную ошибку.

## Heredoc и Nowdoc

Оба синтаксиса — для многострочных строк без экранирования кавычек.

| Синтаксис | Аналог | Интерполяция |
| --- | --- | --- |
| **Heredoc** | Двойные кавычки | Да |
| **Nowdoc** | Одинарные кавычки | Нет |

### Синтаксис

```php
// Heredoc
$str = <<<EOD
Текст
EOD;

// Nowdoc — идентификатор в одинарных кавычках
$str = <<<'EOD'
Текст с $переменной (не интерполируется)
EOD;
```

**PHP 5.3+:** открывающий идентификатор Heredoc может быть в двойных кавычках: `<<<"EOD"`.

**PHP 7.3+ (гибкий синтаксис):**

- закрывающий идентификатор может быть с отступом, отступ удаляется из всех строк;
- перевод строки после закрывающего идентификатора больше не обязателен.

```php
$str = <<<EOD
    Строка 1
    Строка 2
    EOD;
// Результат: "Строка 1\nСтрока 2"
```

### Практическое применение

- Многострочные HTML-шаблоны (Heredoc).
- SQL-запросы (Nowdoc — чтобы `$` в SQL не интерполировались).
- Генерация кода, конфигов.

**Важно:** пробелы внутри Heredoc/Nowdoc сохраняются как есть.

## Основные функции для работы со строками

| Функция | Описание |
| --- | --- |
| `strlen($str)` | Длина в байтах |
| `mb_strlen($str)` | Длина в символах (UTF-8) |
| `strpos($str, $needle)` | Позиция подстроки |
| `substr($str, $start, $len)` | Подстрока |
| `str_replace($search, $replace, $str)` | Замена |
| `trim($str)` | Удаление пробелов по краям |
| `strtolower($str)` | Нижний регистр |
| `strtoupper($str)` | Верхний регистр |
| `sprintf($format, ...)` | Форматирование |

```php
$str = "Привет";
var_dump(strlen($str));     // int(12) — байты
var_dump(mb_strlen($str));  // int(6) — символы
```
