# PHP Algorithms

Коллекция алгоритмических задач на PHP 8 для закрепления базовых конструкций:
условия, циклы, массивы, функции.

Часть учебного проекта [php-the-right-way](../) — [ветка main](https://github.com/SystemDataBaseAdministrator002/php-the-right-way/tree/main).

## Список задач

| # | Задача |
|---|---|
| 01 | Проверка на чётность |
| 02 | Проверка возраста |
| 03 | Наибольшее из трёх чисел |
| 04 | Определение сезона по месяцу |
| 05 | Калькулятор |
| 06 | Вывести числа от 1 до 10 |
| 07 | Чётные числа от 1 до 20 |
| 08 | Факториал числа |
| 09 | Таблица умножения |
| 10 | Числа Фибоначчи |
| 11 | Массив от 1 до 5 |
| 12 | Сумма элементов массива |
| 13 | Максимум в массиве |
| 14 | Перевернуть массив |
| 15 | Делимость на 3 и на 5 |
| 16 | Светофор (if, switch, match) |

## Запуск

Открой в браузере любую задачу:

    http://localhost/php-the-right-way/01-even-check/

(предполагается, что ветка `php-algorithms` находится в `C:\xampp\htdocs\php-the-right-way`)

## Связанные ветки

- **`main`** — 30 уроков курса Learn PHP The Right Way
- **`php-algorithms`** — текущая ветка, 16 алгоритмических задач

## Требования

- PHP 8.2+
- Apache (XAMPP) или встроенный сервер PHP
