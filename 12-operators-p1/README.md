Этот урок — туториал по операторам в PHP 8: типы, приоритет, особенности.

## Классификация операторов

### По количеству операндов

| Тип | Операндов | Примеры |
| --- | --- | --- |
| **Унарные** | 1 | `++`, `--`, `!`, `~`, `(int)`, `@` |
| **Бинарные** | 2 | `+`, `-`, `*`, `/`, `==`, `&&`, `.` |
| **Тернарные** | 3 | `?:` (только условный оператор) |

**Важно:** `??` и `??=` — **бинарные** операторы, а не тернарные.

### По функциональному назначению

| Группа | Операторы |
| --- | --- |
| **Арифметические** | `+`, `-`, `*`, `/`, `%`, `**` |
| **Присваивания** | `=`, `+=`, `-=`, `*=`, `/=`, `.=`, `%=`, `**=`, `??=` |
| **Сравнения** | `==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`, `<=>` |
| **Логические** | `&&`, `\|\|`, `!`, `and`, `or`, `xor` |
| **Строковые** | `.`, `.=` |
| **Битовые** | `&`, `\|`, `^`, `~`, `<<`, `>>` |
| **Инкремент/декремент** | `++`, `--` |
| **Условные** | `?:`, `??` |
| **Подавление ошибок** | `@` |

## Арифметические операторы

```php
$x = 10;
$y = 3;

var_dump($x + $y);    // int(13)
var_dump($x - $y);    // int(7)
var_dump($x * $y);    // int(30)
var_dump($x / $y);    // float(3.333...)
var_dump($x % $y);    // int(1)
var_dump($x ** $y);   // int(1000)
```

### Особенности

**Деление `/`:**

- Если операнды — целые числа и деление нацело, результат `int` (PHP 8+).
- Если хотя бы один операнд — `float`, результат `float`.
- Если деление не нацело — результат `float`.

```php
var_dump(10 / 2);    // int(5)
var_dump(10 / 3);    // float(3.333...)
var_dump(10.0 / 2);  // float(5.0)
```

**Деление на ноль:**

В PHP 8 выбрасывается исключение `DivisionByZeroError`:

```php
try {
    $result = 1 / 0;
} catch (DivisionByZeroError $e) {
    echo 'Деление на ноль!';
}
```

Для безопасного деления — `fdiv()`:

```php
var_dump(fdiv(1, 0));    // float(INF)
var_dump(fdiv(-1, 0));   // float(-INF)
var_dump(fdiv(0, 0));    // float(NAN)
```

**Модуль `%`:**

- Операнды приводятся к `int`.
- Знак результата берётся от делимого.

```php
var_dump(10 % 3);    // int(1)
var_dump(-10 % 3);   // int(-1)
var_dump(10 % -3);   // int(1)
```

**Целочисленное деление — `intdiv()`:**

```php
var_dump(intdiv(10, 3));   // int(3)
```

**Переполнение:**

```php
var_dump(PHP_INT_MAX + 1);   // float(9.2233720368548E+18)
```

## Операторы присваивания

```php
$a = 5;
$b = $a = 10;          // $a = 10, $b = 10
$c = ($a = 5) + 2;     // $a = 5, $c = 7

$count = 0;
$count += 5;           // $count = 5
$count -= 2;           // $count = 3
$count *= 2;           // $count = 6
```

**`??=` (PHP 7.4+):**

```php
$array['key'] ??= 'default';   // Присваивает, если ключ не существует или null
```

## Операторы сравнения

| Оператор | Описание |
| --- | --- |
| `==` | Равно (с приведением типов) |
| `===` | Идентично (значение и тип) |
| `!=`, `<>` | Не равно |
| `!==` | Не идентично |
| `<`, `>` | Меньше, больше |
| `<=`, `>=` | Меньше или равно, больше или равно |
| `<=>` | Космический корабль |

`<=>` возвращает:

- `-1` — если левый меньше правого;
- `0` — если равны;
- `1` — если левый больше правого.

```php
var_dump(1 <=> 2);   // int(-1)
var_dump(2 <=> 2);   // int(0)
var_dump(3 <=> 2);   // int(1)
```

**Сравнение строк и чисел в PHP 8.0:**

- Если оба операнда — числовые строки, или один — число, а другой — числовая строка: сравнение численно.
- Если строка не числовая: число преобразуется в строку, сравнение строковое.

```php
var_dump(0 == "0");     // true (числовое)
var_dump(0 == "abc");   // false (строковое: "0" vs "abc")
var_dump("1" == "01");  // true (числовое)
```

## Логические операторы

| Оператор | Описание |
| --- | --- |
| `&&` | И (высокий приоритет) |
| `\|\|` | ИЛИ (высокий приоритет) |
| `!` | НЕ |
| `and` | И (низкий приоритет) |
| `or` | ИЛИ (низкий приоритет) |
| `xor` | Исключающее ИЛИ |

**Приоритет `&&` vs `and`:**

```php
$a = true && false;   // $a = false (&& выше)
$a = true and false;  // $a = true (and ниже, чем =)
```

## Тернарный оператор

```php
$status = $isPaid ? 'paid' : 'unpaid';
```

**Вложенные тернарные операторы (PHP 8):**

В PHP 8 вложенные тернарные операторы без скобок вызывают ошибку компиляции:

```php
// PHP 8: Fatal error
// $result = $a ? $b : $c ? $d : $e;

// Правильно:
$result = $a ? $b : ($c ? $d : $e);
```

---

## Оператор `??` (null coalescing)

```php
$username = $_GET['user'] ?? 'guest';
$value = $a ?? $b ?? $c ?? 'default';
```

### `??` vs `?:`

| | `??` | `?:` |
| --- | --- | --- |
| Проверяет | `null` / не определена | «Ложность» (`false`, `0`, `""`) |
| Warning для неопределённой | Нет | Да |
| Пример | `$a ?? 'default'` | `$a ?: 'default'` |

---

## Изменение приоритета `.` в PHP 8.0

В PHP 8.0 приоритет конкатенации `.` понижен. Раньше `.` имел тот же приоритет, что `+` и `-`.

```php
// PHP 7: 'Result: ' . ($a + $b)
// PHP 8: ('Result: ' . $a) + $b — потенциальный TypeError
echo 'Result: ' . 1 + 2;
```

**Совет:** всегда используй скобки для ясности.
