Этот урок — туториал по приоритету и ассоциативности операторов в PHP 8.

## Приоритет операторов

**Приоритет** определяет, какой оператор выполняется раньше в выражении. Операторы с более высоким приоритетом выполняются первыми.

```php
$x = 5 + 3 * 5;   // 3 * 5 = 15, затем 5 + 15 = 20
```

Скобки переопределяют приоритет:

```php
$x = (5 + 3) * 5;   // 8 * 5 = 40
```

Вложенные скобки работают «изнутри наружу»:

```php
$c = 2 * (3 + (4 * 5));   // 4 * 5 = 20, 3 + 20 = 23, 2 * 23 = 46
```

## Ассоциативность

Если у операторов одинаковый приоритет, порядок вычисления определяется ассоциативностью:

| Ассоциативность | Направление | Примеры |
| --- | --- | --- |
| **Левая** | Слева направо | `*`, `/`, `%`, `+`, `-`, `.` |
| **Правая** | Справа налево | `**`, `=`, `??` |
| **Отсутствующая** | Нельзя использовать рядом | `<`, `>`, `==`, `===`, `?:` (PHP 8) |

Левая ассоциативность:

```php
$x = 10 / 2 * 3;   // (10 / 2) * 3 = 15
```

Правая ассоциативность:

```php
$a = $b = 5;   // $b = 5, затем $a = 5
```

Отсутствующая ассоциативность:

```php
// PHP 8: Fatal error
// $result = $a ? $b : $c ? $d : $e;

// Правильно:
$result = $a ? $b : ($c ? $d : $e);
```

## Приоритет логических операторов

| Оператор | Приоритет |
| --- | --- |
| `!` | Высокий |
| `&&` | Средний |
| `\|\|` | Средний |
| `and` | Низкий |
| `xor` | Низкий |
| `or` | Низкий |

```php
$x = true || false && false;
// && выше ||, поэтому: true || (false && false) = true

$y = (true || false) && false;
// Скобки меняют: (true) && false = false

$z = $a = 5 and $b = 10;
// and ниже =, поэтому: ($z = ($a = 5)) and ($b = 10)
// $a = 5, $z = 5, $b = 10

$w = $a = 5 && $b = 10;
// && выше =, поэтому: $w = (($a = 5) && ($b = 10))
// $a = 5, $b = 10, $w = true
```

## Изменение приоритета `.` в PHP 8.0

В PHP 8.0 приоритет конкатенации `.` понижен:

```php
// PHP 7: 'Result: ' . (1 + 2) = 'Result: 3'
// PHP 8: ('Result: ' . 1) + 2 — TypeError
echo 'Result: ' . 1 + 2;

// Правильно:
echo 'Result: ' . (1 + 2);
```

## Ассоциативность `??`

`??` правоассоциативен:

```php
$a = null;
$b = null;
$c = 'value';

$result = $a ?? $b ?? $c;   // 'value'
// Группируется как: $a ?? ($b ?? $c)
```

## Рекомендации

- Всегда используй скобки, если выражение нетривиально.
- Не полагайся на запоминание всех приоритетов — даже опытные разработчики ставят скобки.
- Проверяй приоритет в официальной документации PHP.
