## Оператор контроля ошибок `@`

Ставится перед выражением и подавляет вывод сообщений об ошибках:

```php
$value = @file_get_contents('nonexistent.txt');
// Warning не выводится, $value = false
```

**Важно:**

- Подавляет только нефатальные ошибки: `E_WARNING`, `E_NOTICE`, `E_DEPRECATED`, `E_STRICT`.
- Не подавляет `E_ERROR`, `E_PARSE`, `E_CORE_ERROR`, `E_COMPILE_ERROR`.
- Работает с любым выражением, но не с языковыми конструкциями (`echo`, `if`, `while`).
- Имеет высокий приоритет (наравне с `++`, `--`, `~`). Скобки рекомендуются для ясности:

```php
@(someFunction() + anotherFunction());
```

- Не отменяет вызов `set_error_handler()`. Обработчик всё равно получит уведомление.
- **Не рекомендуется в продакшене**: скрывает проблемы, усложняет отладку.

**Альтернативы:**

```php
// Проверка перед операцией
if (file_exists('file.txt')) {
    $value = file_get_contents('file.txt');
}

// try-catch для исключений
try {
    $result = $pdo->query('SELECT * FROM table');
} catch (PDOException $e) {
    // ...
}
```

## Операторы инкремента и декремента

| Форма | Синтаксис | Действие |
| --- | --- | --- |
| Префиксный инкремент | `++$a` | Сначала +1, потом возврат |
| Постфиксный инкремент | `$a++` | Сначала возврат, потом +1 |
| Префиксный декремент | `--$a` | Сначала -1, потом возврат |
| Постфиксный декремент | `$a--` | Сначала возврат, потом -1 |

```php
$a = 5;
$b = $a++;   // $b = 5, $a = 6
$c = ++$a;   // $a = 7, $c = 7
```

**Правила для разных типов:**

- **Числа** — работают как обычно.
- **Строки** — инкремент работает (alphabetical increment): `'a'++` → `'b'`. Декремент не работает.
- **`null`** — инкремент даёт `1`, декремент не даёт эффекта.
- **`bool`** — ни инкремент, ни декремент не дают эффекта.
- **Массивы, объекты, ресурсы** — не затрагиваются.

## Логические операторы

| Оператор | Символ | Приоритет | Описание |
| --- | --- | --- | --- |
| AND | `&&` | Высокий | И |
| OR | `\|\|` | Высокий | ИЛИ |
| NOT | `!` | Высокий | НЕ |
| AND | `and` | Низкий | И |
| OR | `or` | Низкий | ИЛИ |
| XOR | `xor` | Низкий | Исключающее ИЛИ |

**Таблица истинности:**

| `$a` | `$b` | `$a && $b` | `$a \|\| $b` | `$a xor $b` | `!$a` |
| --- | --- | --- | --- | --- | --- |
| `true` | `true` | `true` | `true` | `false` | `false` |
| `true` | `false` | `false` | `true` | `true` | `false` |
| `false` | `true` | `false` | `true` | `true` | `true` |
| `false` | `false` | `false` | `false` | `false` | `true` |

**Короткое замыкание:**

```php
false && someFunction();   // someFunction() не вызовется
true || someFunction();    // someFunction() не вызовется
```

**Разница приоритетов:**

```php
$a = true && false;   // $a = false (&& выше =)
$b = true and false;  // $b = true (and ниже =)
```

## Побитовые операторы

| Оператор | Символ | Пример | Результат |
| --- | --- | --- | --- |
| AND | `&` | `5 & 3` | `1` |
| OR | `\|` | `5 \| 3` | `7` |
| XOR | `^` | `5 ^ 3` | `6` |
| NOT | `~` | `~5` | `-6` |
| Сдвиг влево | `<<` | `5 << 1` | `10` |
| Сдвиг вправо | `>>` | `5 >> 1` | `2` |

```php
var_dump(5 & 3);    // int(1)  — 0101 & 0011 = 0001
var_dump(5 | 3);    // int(7)  — 0101 | 0011 = 0111
var_dump(5 ^ 3);    // int(6)  — 0101 ^ 0011 = 0110
var_dump(~5);       // int(-6)
var_dump(5 << 1);   // int(10)
var_dump(5 >> 1);   // int(2)
```

**Применение:** шифрование, флаги, разрешения.

## Операторы массивов

| Оператор | Описание |
| --- | --- |
| `+` | Объединение (union) |
| `==` | Равны (те же пары ключ-значение) |
| `===` | Идентичны (те же пары, порядок, типы) |
| `!=`, `<>` | Не равны |
| `!==` | Не идентичны |

```php
$a = ['x' => 1, 'y' => 2];
$b = ['y' => 3, 'z' => 4];

var_dump($a + $b);   // ['x' => 1, 'y' => 2, 'z' => 4] — 'y' не перезаписывается

var_dump([1, 2] == [1, 2]);      // true
var_dump([1, 2] === [1, 2]);     // true
var_dump([1, 2] === ['1', '2']); // false (разные типы)
var_dump([1, 2] === [2, 1]);     // false (разный порядок)
```

## Оператор исполнения (backticks)

Выполняет команду в оболочке и возвращает вывод:

```php
$output = `ls -la`;
echo $output;
```

Эквивалентен `shell_exec()`. Использовать с осторожностью из-за безопасности.
