## Что такое константы

Константа — это именованное значение, которое **нельзя изменить** после определения. В отличие от переменных:

- константа не имеет знака `$` перед именем;
- константу нельзя удалить через `unset()`;
- константа автоматически доступна во всём скрипте, включая функции (глобальная область видимости);
- попытка переопределить константу вызовет предупреждение.

Способы определения:

```php
// Через define() — вычисляется в рантайме
define('SITE_NAME', 'My Site');

// Через const — вычисляется на этапе компиляции
const VERSION = '8.4';
```

Имена констант чувствительны к регистру (`SITE_NAME` и `site_name` — разные константы). До PHP 7.3 `define()` позволял создавать регистронезависимые константы через третий аргумент, но в PHP 8.0 эта возможность удалена.

## Различия между `define()` и `const`

| Характеристика | `const` | `define()` |
|:--- |:--- |:--- |
| Когда вычисляется | Компиляция | Выполнение (рантайм) |
| Можно внутри `if`/циклов/функций | Нет | Да |
| Динамическое имя | Нет | Да |
| Динамическое значение (функция, переменная) | Нет | Да |
| Внутри класса | Да (константа класса) | Нет |
| Хранение массивов | Да (PHP 7+) | Да (PHP 7+) |
| Производительность | Быстрее | Медленнее |

Пример условного определения:

```php
if (!defined('DEBUG')) {
    define('DEBUG', true);
}
```

Пример динамического имени:

```php
$key = 'MAX_USERS';
define($key, 100);
echo MAX_USERS;   // 100
```

Попытка использовать переменную в `const` вызовет ошибку:

```php
$time = time();
const TIME = $time;    // Fatal error
define('TIME', $time); // OK
```

## Проверка и чтение констант

- `defined('NAME')` — проверяет, существует ли константа. Возвращает `true` или `false`.
- `constant('NAME')` — возвращает значение константы, когда её имя хранится в переменной.

```php
define('TIMEOUT', 30);

if (defined('TIMEOUT')) {
    echo constant('TIMEOUT');   // 30
}
```

## Виды констант

Помимо пользовательских, в PHP есть:

- **предопределённые константы** — например, `PHP_VERSION`, `PHP_INT_MAX`, `E_ERROR`.
- **магические константы** — их значение меняется в зависимости от контекста. Все они вычисляются на этапе компиляции и нечувствительны к регистру.

| Константа | Что возвращает |
|:--- |:--- |
| `__LINE__` | Номер текущей строки |
| `__FILE__` | Полный путь к файлу |
| `__DIR__` | Директория файла |
| `__FUNCTION__` | Имя функции |
| `__CLASS__` | Имя класса |
| `__METHOD__` | Имя метода класса |
| `__NAMESPACE__` | Имя пространства имён |

## Переменные переменные

Переменная переменная принимает значение переменной и использует его как имя новой переменной. Это позволяет динамически создавать переменные:

```php
$foo = 'bar';
$$foo = 'baz';

echo $foo;   // bar
echo $bar;   // baz
```

Работает и с массивами:

```php
$foo = ['bar' => 'baz'];
$$foo['bar'] = 'qux';   // создаст переменную $baz
```

Переменные переменные — плохая практика в продакшене: они затрудняют чтение кода, отладку и статический анализ. Использовать только в исключительных случаях.

---

## Когда использовать константы

Константы применяют для статических данных, которые не меняются:

- версии приложения;
- статусы («оплачен», «аннулирован», «ожидание»);
- пути к директориям;
- настройки подключения к БД.

С PHP 7 можно хранить в константах массивы:

```php
const ALLOWED_ROLES = ['admin', 'editor', 'viewer'];
```

---

## Дополнительно: константы класса (забегая вперёд)

`const` может использоваться внутри классов:

```php
class Status {
    const PAID = 'paid';
    const CANCELLED = 'cancelled';
}

echo Status::PAID;   // paid
```

`define()` внутри класса не создаёт константу класса в привычном смысле. Подробно разберём в уроках по ООП.
