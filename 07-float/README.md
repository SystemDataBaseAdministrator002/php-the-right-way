# Тип данных Float (числа с плавающей запятой)

> Учебное пособие по PHP 8 · [Видеоурок](https://www.youtube.com/watch?v=d3c_OOD4Jzs&list=PLr3d3QYzkw2xabQRUpcZ_IBk9W50M9pe-&index=8&pp=iAQB)

Этот урок — туториал по типу данных `float` в PHP 8.

## Что такое числа с плавающей запятой

Float (также известный как `double` или `real`) — число с десятичной точкой. Может быть представлено в экспоненциальной форме:

```php
$a = 1.234;
$b = 1.2e3;      // 1200.0
$c = 7E-10;      // 0.0000000007
$d = 1_234.567;  // PHP 7.4+
```

Размер `float` зависит от платформы, но PHP обычно использует IEEE 754 double precision (64 бита): максимум ≈ 1.8e308, точность ≈ 14–15 десятичных цифр.

## Константы диапазона (PHP 7.2+)

| Константа | Что означает |
| --- | --- |
| `PHP_FLOAT_MAX` | Наибольшее представимое положительное число (≈ 1.8e308) |
| `PHP_FLOAT_MIN` | Наименьшее положительное нормализованное число (≈ 2.2e-308) |
| `PHP_FLOAT_DIG` | Количество десятичных цифр без потери точности (15 на 64-бит) |
| `PHP_FLOAT_EPSILON` | Машинный эпсилон: наименьшее `x`, для которого `x + 1.0 != 1.0` |

## Проблема точности

`float` в PHP хранятся в двоичном формате, но большинство десятичных дробей нельзя представить точно:

```php
var_dump(0.1 + 0.7);              // float(0.7999999999999999)
var_dump(floor((0.1 + 0.7) * 10)); // float(7), а не 8!
```

Из этого следуют два правила:

- Не доверяй последним цифрам `float`-вычислений.
- Никогда не сравнивай `float` на прямое равенство (`==` или `===`).

## Как сравнивать float правильно

```php
function floatsAreEqual(float $a, float $b, float $epsilon = PHP_FLOAT_EPSILON): bool
{
    return abs($a - $b) < $epsilon;
}

var_dump(floatsAreEqual(0.1 + 0.2, 0.3)); // bool(true)
var_dump(0.1 + 0.2 === 0.3);             // bool(false)
```

## Особые значения

| Значение | Что означает | Как получить |
| --- | --- | --- |
| `INF` | Положительная бесконечность | `PHP_FLOAT_MAX * 2` |
| `-INF` | Отрицательная бесконечность | `-PHP_FLOAT_MAX * 2` |
| `NAN` | «Не число» | `acos(2)`, `0/0` |

**Важно:** `NAN !== NAN` — единственное значение, не равное самому себе.

## Функции проверки

```php
is_finite($val);    // true, если не INF и не NAN
is_infinite($val);  // true для INF и -INF
is_nan($val);       // true для NAN
```

## Преобразование типов

### В `float`

| Способ | Синтаксис |
| --- | --- |
| Приведение типа | `(float) $value` |
| Функция | `floatval($value)` |

Правила преобразования строк:

- числовая строка → `float`: `(float) "12.5"` → `12.5`
- строка с числом в начале → числовая часть: `(float) "12.5abc"` → `12.5`
- нечисловая строка → `0` (в PHP 8+ с `TypeError`/`Warning` в арифметическом контексте)

```php
var_dump(floatval('122.34343The')); // float(122.34343)
var_dump(floatval('The122.34343')); // float(0)
```

### Из `float`

- `int` → `float`: автоматически при арифметике.
- **PHP 8.1+**: неявное преобразование `float` → `int` с потерей точности вызывает deprecation notice.

## Дополнительно

- **Float в строку:** PHP использует настройку `precision` (по умолчанию 14 цифр). Для большей точности — `ini_set('precision', -1)`.
- **Подчёркивания:** `1_234.567_89` — PHP игнорирует подчёркивания.
- **Точные вычисления:** для денег и точных расчётов используй `bcmath` или `gmp`, а не `float`.
